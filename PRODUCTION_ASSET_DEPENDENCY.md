## Promotion Strategy

```
Current Production Directory
  ├── dashboard_comparison_*.csv       (EV_CHANGED)
  ├── integration/
  │   ├── ev_actuals_*.csv            (EV_CHANGED)
  │   ├── monthly_forecast_*.csv       (EV_CHANGED)
  │   ├── metadata.json               (SHARED_METADATA_CHANGED)
  │   ├── hp_*.csv                    (COPIED_UNCHANGED - byte identical)
  │   └── hp_metadata.json            (COPIED_UNCHANGED - byte identical)

Promotion Process:
1. Create candidate_dir as clone of current production_dir
2. Replace EV_CHANGED files with validated candidate versions
3. Update SHARED_METADATA_CHANGED fields (EV vintage)
4. Verify COPIED_UNCHANGED files are byte-identical to current
5. Atomic directory rename: production_dir ← candidate_dir
6. Post-promotion validation:
   - All 19 files present
   - All files readable
   - EV files contain correct vintage
   - HP files byte-identical to pre-promotion
   - Dashboard can load all files
```

# Validation: After directory swap
